## Data and Privacy Boundaries

The following categories of files **must not** be committed to the repository:

- Raw MIMIC-III / eICU patient data
- UMLS, SNOMED-CT, and RxNorm source files
- Processed patient-level tensors and pickles
- Model checkpoints (`.pt`, `.pth`, `.ckpt`, `.pkl`, `.pickle`, `.parquet`)
- Evaluation outputs containing protected health information

These exclusions are enforced by `.gitignore` and verified by the Day 48 reproducibility audit script.
