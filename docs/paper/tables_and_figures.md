# Tables and Figures

The paper's tables and figures are generated by the Phase 7 evaluation scripts and stored as
aggregate CSV / PNG / JSON under `artifacts/phase7/`. This page is the index; it does not
duplicate the data files. A machine-readable version is
[`artifacts/phase8/paper_asset_index.json`](../../artifacts/phase8/paper_asset_index.json).

## Tables

| Paper table | Source file | Contents |
|---|---|---|
| Table 1 — Dataset summary | `artifacts/phase7/tables/table1_dataset_summary.csv` | benchmark-v2 record/anomaly counts, split sizes, subject overlap, trivial-signal gate, coverage |
| Table 2 — Main results | `artifacts/phase7/tables/table2_main_results.csv` | ROC-AUC + CI, AP, F1 for the four variants |
| Table 3 — Ablation | `artifacts/phase7/tables/table3_ablation_results.csv` | rule-family ROC-AUC / AP / normal-FP |
| Table 4 — Counterfactual | `artifacts/phase7/tables/table4_counterfactual_results.csv` | attempted / flagged / success / ΔS_ont / edits |
| Table 5 — Statistical tests | `artifacts/phase7/tables/table5_statistical_tests.csv` | paired-bootstrap diffs, CIs, p-values |

## Figures

| Paper figure | Source file(s) | Contents |
|---|---|---|
| Fig 1 — Pipeline summary | `artifacts/phase7/figures/fig1_pipeline_summary.json` | method/benchmark/scope summary (data for a schematic) |
| Fig 2 — Main ROC-AUC bar | `artifacts/phase7/figures/fig2_main_auc_bar.{png,csv}` | ROC-AUC with CIs across variants |
| Fig 3 — Ablation ROC-AUC bar | `artifacts/phase7/figures/fig3_ablation_auc_bar.{png,csv}` | rule-family ablation |

## Regeneration

```bash
python scripts/run_phase7_final_evaluation.py
python scripts/run_phase7_ablations.py
python scripts/run_phase7_counterfactual_final.py
python scripts/run_phase7_tables.py
```

The `.png` figures and `.csv`/`.json` figure data are committed (aggregate only). Per-record
score dumps behind these summaries are git-ignored.
